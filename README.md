# 天气看板

一个简洁的天气实时查看工具。
目的是为了解决老旧IpadMini用作天气查看器时，没有合适应用，也没有支持旧版safari的公开站点。

## 特性

- **实时天气数据**: 基于 Open-Meteo API 提供精确的北京地区天气信息
- **统一设计风格**: 采用柔和的浅灰蓝渐变背景，视觉舒适
- **详细天气信息**: 显示温度、湿度、风速及天气图标和文字描述
- **多时段预报**: 
  - 当前天气详情
  - 未来24小时逐时预报
  - 未来7天天气趋势
- **响应式布局**: 适配各种屏幕尺寸，包括 iPad Mini
- **自动刷新**: 每3分钟自动更新最新天气数据
- **错误处理**: 网络异常时提供友好的错误提示和重试功能

## 技术栈

- **HTML5/CSS3**: 构建页面结构和样式
- **JavaScript**: 实现数据获取和页面交互
- **Open-Meteo API**: 获取免费的天气数据
- **WMO天气代码**: 标准化的天气状况表示

## 功能说明

### 天气信息展示
- 当前温度、天气状况、湿度、风速
- 未来24小时逐时温度和天气变化
- 未来7天最高最低温度预报

### 界面特色
- 半透明卡片设计，带有毛玻璃效果
- 平滑的动画过渡效果
- 直观的天气图标和中文描述

## 使用方法

1. 直接打开 `index.html` 文件即可使用
2. 页面会自动获取北京地区的天气数据
3. 数据每3分钟自动更新一次
4. 网络异常时点击"重试"按钮手动刷新、
5. 建议部署在家庭内网服务器上，并将天气API换成http接口，可以保证旧版ipad能正常加载数据。
  - 旧版ipad安全控制不允许本地打开的html请求http接口，并且旧版本ipad也不支持当下新的CA认证模式，所以用不了GitHub Pages部署的页面)
   

## API 说明

本项目使用 Open-Meteo 的免费天气 API:
- 地理位置: 北京 (39.9042°N, 116.4074°E)
- 数据类型: 温度、湿度、天气代码、风速
- 更新频率: 每日多次更新
